# Esolv - E-Commerce Solutions Website

A pixel-accurate, high-performance, and 100% mobile/tablet-responsive multi-page website for Esolv.

---

## 🔗 Live Preview

- **Local Web Server**: Run `node server.js` and open [http://localhost:3000](http://localhost:3000)
- **GitHub Pages**: View live on GitHub Pages.
